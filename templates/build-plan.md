## 阶段性验收节点

阶段性节点使用 `N01`、`N02` 等编号。同一建设批次的节点共用一次 Building Audit，运行时按节点分别审计和接受。批次使用 `B01`、`B02` 等编号。后续批次的 Task Spec 可先保留草案，等前置建设要求满足后定稿并批准。

前置建设要求填写「无」或「N01、N02 已验收」，可在句号后写明须据此定稿的内容。Runtime 前置节点约束运行顺序。各节点的实际运行授权由 Harness 记录。全部节点获接受后另行开展最终全链条 Runtime Audit。

| 节点 ID | 节点目的 | 建设批次 | 前置建设要求 | 包含的运行步骤 | Runtime 前置节点 | 阶段性成果与验收条件 |
